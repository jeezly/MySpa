MYSPA — INSTALACIÓN EN WINDOWS (CMD)
====================================
REQUISITOS: Node.js 22 LTS, MySQL Server 8 encendido, conexión root/root.

1) Guarda MySpa.zip en la carpeta Descargas de Windows.
2) Abre CMD y pega, uno por uno:

cd /d D:\heezl\Escritorio\rafa
mkdir MySpa
tar -xf "%USERPROFILE%\Downloads\MySpa.zip" -C "D:\heezl\Escritorio\rafa\MySpa"
cd MySpa
npm install
npm run setup
npm run dev

3) Abre http://127.0.0.1:5173
4) Abre CREDENCIALES_LOCALES.txt para ver las contraseñas demo.

Si no te funciona el comando tar, extrae manualmente el contenido
DIRECTAMENTE en D:\heezl\Escritorio\rafa\MySpa, sin carpeta duplicada.

SQL Workbench: database\01_schema.sql (el setup también lo ejecuta).
PWA instalable: detén npm run dev con Ctrl+C y ejecuta npm run pwa,
luego abre http://localhost:4000 en Chrome/Edge.
Pruebas de reglas: npm run test
Prueba de API real: npm run smoke (mientras npm run dev está ejecutándose)

IMPORTANTE: MySQL Workbench no sustituye a MySQL Server.
