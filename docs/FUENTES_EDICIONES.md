# Fuentes de las ediciones del catálogo ampliado

Las fichas usan el ISBN de **una edición concreta**. No se debe confundir el año de
esa edición con el año original de la obra. Títulos y editoriales se mantienen
según la edición seleccionada, generalmente en inglés; las sinopsis son
paráfrasis originales redactadas en español para la demostración de MySpa.

Las portadas se muestran, cuando están disponibles, mediante el servicio externo
`https://covers.openlibrary.org/b/isbn/<ISBN>-L.jpg?default=false`. Este servicio
no garantiza una portada para todos los ISBN ni su disponibilidad permanente.
No se almacenan en el repositorio las imágenes editoriales.

**Nota de inventario:** los ejemplares creados por el script son datos de
prueba y no representan existencias físicas verificadas en una biblioteca real.

**Nota de autores:** la base de datos original requiere un correo electrónico
no nulo para todos los autores. Como no se deben inventar direcciones reales,
los registros añadidos usan marcadores internos con dominio `.invalid` y la
API pública omite estos marcadores en las fichas.
